Черновик сохраняется в этом браузере.

У каждого вопроса четыре варианта. Отметь кружком один правильный ответ — номера в JSON подставятся автоматически.

Как добавить картинку и запустить игру?

Вставь прямую HTTPS-ссылку на картинку или путь вида images/photo.jpg. Во втором случае загрузи сам файл в папку images своего сайта. Картинка не встраивается в JSON.

После скачивания открой «Перейти к игре», выбери полученный JSON и создай комнату. Собственные файлы с правильными ответами не загружай в публичный репозиторий GitHub.

Черновик хранится только в этом браузере. Скачанный файл — твоя резервная копия. Смена браузера или очистка его данных удалит черновик. Для шрифта и внешних картинок нужен интернет.
